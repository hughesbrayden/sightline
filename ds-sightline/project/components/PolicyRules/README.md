# PolicyRules

Shows the evolved policy as plain rules a person can read, each tagged with the generation that discovered it.

**The consumer provides** `rules`, a list of `{ text, gen }`, in the order they apply.

**Rules**
- One sentence per rule, in the imperative, in words a responder would use: "Drop accounts that never match a drone pass."
- Every rule carries its generation tag. A rule without provenance doesn't belong here.
- This is the closing card of the demo: the policy is the artifact. Give it room.
